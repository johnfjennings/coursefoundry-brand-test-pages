Week 7 Practical Exam (In-class): GADV 06015 - Immersive Technology Foundations

Author

Mr. John Jennings

Introduction

This lesson walks you through the Week 7 Practical Exam for GADV 06015 - Immersive Technology Foundations. The exam tests your ability to create an original Unity3D application that uses materials, 3D primitive objects, sounds, and simple scripts.

You will not be asked to create original 3D models, materials, textures, or sound recordings. You should only use primitive objects in Unity, and you are free to use any of the assets provided in the asset package available in Moodle.

You will have a total of 1 hour 45 minutes to complete the assignment.

Task 1 - Project Setup (10%)

Follow these steps to set up your project:

  1. Accept the GitHub Classroom Assignment from the link provided to you.
  2. Clone the empty repository to your computer.
  3. Create a new Unity project named GADV06015-K00000000-PracticalExam_Unity (replace K00000000 with your K-number):
    • Use Unity version 2022.3.x
    • Select the template “Universal 3D Core”
    • Save the Unity project to the repo folder from the previous step
  4. Download and import the asset package named GADV06015-2026-exam-assets.unitypackage, available on Moodle:
    • Import the asset package into your Unity project
  5. Change the Company Name and Project Name in Player Settings as follows:
    • Company Name → Knumber
    • Project Name → 2026-PracticalExam

Task 2 - Create UI and Scene Navigation (30%)

Create a set of scenes that are navigable with a well-designed UI. First, create the scenes in a folder named _Scenes inside the Assets folder.

Name the Scenes as Follows

  1. 0_MainMenu_Scene
    • The game must start in this scene, which should include:
      • Title (give your application a name)
      • Logo (create yourself or use an existing one)
      • Paragraph of text with simple instructions
      • “Credits” button (links to Credits scene)
      • “Play” button (links to Playground scene)
  2. 1_Playground_Scene
    • A Play scene (see Task 3 for details)
  3. 2_Credits
    • This scene should display the game’s title, your name, K-number, date, course, year, and module
    • Add a “Back” button that returns the player to the Main Menu scene
  4. 3_GameOver
    • Display a text message of your choice
    • Add a “Restart” button that returns the player to the Main Menu scene

Task 3 - Create Play Scene (40%)

Create a simple game level that implements the following game design and mechanics.

Environment

Create a playground scene with the following assets:

  • Ground (16m x 16m)
  • Playground boundary wall
  • 4-6 trees (placed in corners of the playground)
  • 1 x swing set (in 1 corner)
  • 1 x picnic area (in 1 corner)
  • 1 x fire pit with seating (in 1 corner)
  • 1 x tube slide (in the centre)
  • 1 x play structure (in 1 corner)
  • 1 x boombox radio (place wherever you like)

Game Mechanics: A Moveable Mouse Player Character

Create a mouse player character:

  • Name it “MousePlayer” in the Hierarchy
  • Add the Main Camera as a child of the mouse object and position it above and to the rear of the mouse, so that the camera follows the mouse

Create a new script called PlayerController and attach it to the mouse. Paste in the following code:

using UnityEngine;

// Controls player movement and rotation.
public class PlayerController : MonoBehaviour
{
    public float speed = 5.0f; // Set player's movement speed.
    public float rotationSpeed = 120.0f; // Set player's rotation speed.
    private Rigidbody rb; // Reference to player's Rigidbody.

    // Start is called before the first frame update
    private void Start()
    {
        rb = GetComponent<Rigidbody>(); // Access player's Rigidbody.
    }

    // Update is called once per frame
    void Update()
    {
    }

    // Handle physics-based movement and rotation.
    private void FixedUpdate()
    {
        // Move player based on vertical input.
        float moveVertical = Input.GetAxis("Vertical");
        Vector3 movement = transform.forward * moveVertical * speed * Time.fixedDeltaTime;
        rb.MovePosition(rb.position + movement);

        // Rotate player based on horizontal input.
        float turn = Input.GetAxis("Horizontal") * rotationSpeed * Time.fixedDeltaTime;
        Quaternion turnRotation = Quaternion.Euler(0f, turn, 0f);
        rb.MoveRotation(rb.rotation * turnRotation);
    }
}

Submission

When you have finished your work:

  • Generate a Windows build of your completed project and place it into a folder named Build in your Unity project.
  • Zip the entire Build folder and upload the zip archive to Moodle.
  • After uploading the Windows build, you must also submit your Unity source code using a git commit to the repository mentioned in Task 1.

Marking Schema

  • 10% - Project Setup
  • 30% - UI and Scene Navigation
  • 40% - Play Scene
  • 20% - Enhancements

Summary

In this lesson, you worked through the structure of the Week 7 Practical Exam for GADV 06015 - Immersive Technology Foundations. You set up a new Unity project and imported the required assets (Task 1), built a navigable set of scenes with a Main Menu, Credits screen, and Game Over screen (Task 2), created a playground environment with a scripted, moveable mouse player character (Task 3), and enhanced the scene with spatial and non-spatial audio and a skybox (Task 4). Together these four tasks make up the full 100% marking schema for the exam, and your completed work must be submitted as both a zipped Windows build and a git commit of your Unity source code.
